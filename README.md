## 📖 Overview

An extended exploration of **Linear Regression** techniques with experiments on different datasets, feature engineering strategies, and model diagnostics. This repository complements the core LinearRegression repo with additional experiments and edge cases.

---

## 🔬 Experiments Included

- Feature scaling impact on regression performance
- Handling multicollinearity with VIF analysis
- Outlier detection and robust regression
- Interaction terms and polynomial features
- Stepwise feature selection
- Residual analysis and diagnostic plots

---

## 📊 Key Analyses

| Analysis | Tool | Purpose |
|----------|------|---------|
| VIF Analysis | statsmodels | Detect multicollinearity |
| Residual Plots | Matplotlib | Check regression assumptions |
| Q-Q Plot | scipy.stats | Normality of residuals |
| Cook's Distance | statsmodels | Identify influential points |
